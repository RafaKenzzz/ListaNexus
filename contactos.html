Transparência

Como tratamos a tua mensagem.

  1. Os teus dados são usados só para responder ao contacto que fizeste.
  2. Não partilhamos nem vendemos dados a terceiros, nem fazemos perfis comerciais.
  3. Se a mensagem contiver dados de terceiros, pedimos-te que avises essas pessoas.
  4. Podes pedir acesso, correção ou eliminação a qualquer momento, por email.
